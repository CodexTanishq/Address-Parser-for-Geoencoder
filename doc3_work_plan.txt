CreditNirvana PS3 — Coordinate Confidence Radius Work Plan
This document sets out the coordinate team’s work to estimate an address pin and a calibrated confidence radius. We will first measure the baseline against surveyed locations, then add reliable visit and landmark evidence, and finally check that each stated radius covers the intended share of held-out addresses.

2. What the Radius Means
For a predicted pin (x̂, ŷ) and a verified location (x, y), the observed distance error is:
e = √((x̂ − x)² + (ŷ − y)²)
R50 is the calibrated radius expected to contain about 50% of similar verified locations. R90 is the calibrated radius expected to contain about 90%. These are coverage targets, not guarantees for an individual address. A useful system reports both accuracy and coverage; it should not claim a small radius unless held-out data supports it.
For each address, the radius should change with evidence quality. Strong, consistent home-confirmed visits and accurate GPS can support a smaller radius. A locality-level baseline, weak GPS, conflicting visits or ambiguous landmarks should lead to a larger radius or a verification recommendation.

Freeze model and radii, then evaluate once on test accounts. Compare against baseline and commercial geocoder on the same verified addresses; run a controlled field pilot.

6. Radius Calibration Details
Baseline-only calibration
For each matched baseline/surveyed address, compute eᵢ. On the calibration split, use the empirical median of eᵢ as the initial R50 and the 90th-percentile value as the initial R90. Repeat by precision category if the groups have adequate sample sizes. This produces a radius appropriate to a group, not an individualized evidence-aware radius.
Dynamic calibration
Let s(x) be an address-specific scale estimate derived from features available at prediction time: baseline precision, GPS accuracy, number and recency of home-confirmed visits, agreement between independent agents, visit-integrity signals, and landmark ambiguity. Fit s(x) using training accounts only. On the separate calibration accounts, calculate zᵢ=eᵢ/s(xᵢ); set q90 to the calibrated 90th-percentile score. For a new address, R90(x)=q90·s(x). Use an analogous q50 for R50. This keeps the radius adaptive while correcting scale under- or over-estimation using observed errors.
For spatial dependence, inspect coverage by town/locality and held-out territory. Local or geographically weighted conformal methods can adapt the calibration to nearby examples, but need enough calibration data; use a global fallback where samples are sparse. Calibration should be refreshed when address mix, territories or field processes change materially.
7. Evaluation and Acceptance Checks
Metric
How to calculate / use it
Median distance error
Median test-set distance from predicted pin to verified home location. Describes typical pin error.
P90 distance error
90th percentile of test-set pin errors. Compare with the commercial geocoder on exactly the same addresses.
Coverage at 90%
Share of test addresses where error ≤ that address’s assigned R90. Target about 90% overall; also inspect town and precision groups.
Radius size
Median/mean assigned R90. Among methods with similar coverage, smaller radii are more useful.
Operational outcomes
In the controlled pilot, track “not traceable” share and productive visits per agent-day alongside coverage.
A method does not pass simply because its radii are large enough to cover everything. Review coverage together with radius size, and show sample counts for every subgroup. Use only home-confirmed locations as address truth where possible; report work/road/unknown meetings separately.

9. Key Point for the Presentation
We will not assign one fixed radius to every address. We will use surveyed locations to measure coordinate errors, learn how errors vary with baseline precision and evidence quality, and calibrate an address-specific R50/R90. The test is whether the stated R90 contains about 90% of held-out verified locations while remaining as small as the evidence allows.
Location evidence is used only for collections and within the DPD period.
