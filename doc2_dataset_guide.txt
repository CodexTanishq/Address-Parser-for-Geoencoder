CreditNirvana PS3 — Dataset Guide & Data Links
Problem Statement 3: Address Geocoder That Learns from Field Visits. This document maps every supplied CSV dataset to the PS3 pipeline, shows the key join relationships, and provides clickable links to the local dataset files.
1. PS3 Core Data Flow
addresses.csv → baseline_geocodes.csv → historical field evidence (field_visits.csv + visit_gps_points.csv) → evidence fusion → predicted location + confidence radius + landmark directions → new field visits → learning loopKey relationship: splits.csv.account_id → field_visits.csv.account_id → field_visits.csv.address_id → addresses.csv.address_id

4. Recommended PS3 Pipeline Mapping
Stage
Dataset(s)
Use
1. Raw address
addresses.csv
address_id, address_text, town_id
2. Address NLP
addresses.csv + landmarks_poi.csv + localities.csv + towns.csv
Extract landmarks, locality, road/cross-road and directional cues.
3. Baseline geocoding
baseline_geocodes.csv
geocoder_x, geocoder_y, precision
4. Historical evidence
field_visits.csv + visit_gps_points.csv
Check-ins, trajectories, GPS accuracy, dwell and outcomes.
5. Visit integrity
field_visits.csv + visit_gps_points.csv + agents.csv
Estimate whether a GPS observation is reliable.
6. Evidence fusion
All Core + Supporting geographic datasets
Combine baseline, semantics, landmarks and reliable historical GPS.
7. Prediction
Model output
Predicted x/y + confidence score + confidence radius.
8. Directions
landmarks_poi.csv
Generate simple landmark-based directions.
9. Ground-truth evaluation
surveyed_addresses.csv + baseline_geocodes.csv
Compare model error against surveyed truth and baseline.
10. Leakage control
splits.csv
Keep train/validation/test accounts separated.
5. Key Point for the Presentation
The most important PS3 feedback loop is: addresses → baseline geocoder → field visits → GPS trajectories → reliable historical location evidence → improved prediction → new field visit evidence. The splits.csv file is used to prevent leakage: its account_id determines whether the corresponding field-visit evidence belongs to train, validation, or test.
